# Lessons learned system

## Idea

Every project folder keeps a short **LESSONS_LEARNED.md** (or a Lessons section in RUN_STEPS.md). Agents and people **read** it before work, **use** it, and **record** new rows when something is learned or fails.

## Files

| File | Use |
|------|-----|
| [TEMPLATE_LESSONS_LEARNED.md](TEMPLATE_LESSONS_LEARNED.md) | Copy into a new project |
| [ROUTING.md](ROUTING.md) | Where to write which kind of lesson |
| [../Agent_Rules/lessons-learned-first.md](../Agent_Rules/lessons-learned-first.md) | Agent workflow |

## Suggested table shape

| Date | What | Why | Do |
|------|------|-----|----|
| mm/dd/yyyy | Short title | Cause / context | Correct action next time |

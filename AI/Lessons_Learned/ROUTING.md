# Where to write a lesson

| Learned about… | Write to |
|----------------|----------|
| This project’s deploy / SQL / UI | Project LESSONS_LEARNED.md |
| Reusable SmartCare product behavior | Shared SmartCare knowledge doc or public SmartCare folder |
| Reusable AI / agent behavior | AI/Agent_Rules/ or this folder |
| Metric / table choice | Data dictionary / concept router (see Guides) |
| One-off client fix | Usually **do not** publish; keep private |

If two places fit, put the detail in the project file and a one-line pointer in the shared hub.

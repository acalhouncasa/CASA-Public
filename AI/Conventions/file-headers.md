# File header templates

When creating a **new** code file, add a short header. Replace placeholders. Use MIT (or your license) for public packs.

## Python

```python
"""
Module: example.py

Author:  [Your name / organization]
Created: YYYY-MM-DD
Last Modified: YYYY-MM-DD

Description:
    ...

License: MIT
"""
```

## SQL

```sql
/*======================================================================================================================
File:    example.sql
Author:  [Your name / organization]
Created: YYYY-MM-DD
Last Modified: YYYY-MM-DD

Purpose:
    ...

Mutates: Y/N
License: MIT
======================================================================================================================*/
```

## PowerShell

```powershell
<#
.SYNOPSIS
  ...

.NOTES
  Author: [Your name / organization]
  Created: YYYY-MM-DD
  License: MIT
#>
```

Do not bump Last Modified on every tiny edit unless you want that discipline.

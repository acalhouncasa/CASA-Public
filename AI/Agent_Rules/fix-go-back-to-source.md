# Fix — go back to the source and relook

When asked to **fix** a generated PDF, HTML, Excel, form, or report:

1. Open the **source that produced it** in this turn.
2. Relook the **same record** that was pointed at.
3. Compare source field + value to the printed label + value before naming the bug.
4. Ship **one check copy** first when the fix would touch a batch.

## Do not

- Treat helper / internal column names as “skip” without reading that row
- Be sure from code comments or a similar record
- Rebuild the full set until the check copy is reviewed, if that gate was requested
- Invent a thinner “wrong” filter than the completeness rule that was stated

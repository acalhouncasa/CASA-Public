# Client Tracking (method)

Streamline’s documented way to make a form due on a repeating interval is **Flags + Tracking Protocols** (Client Tracking), not Document Validations alone.

**Do not test in Prod.**

## Typical setup order

1. **Flag Types** — define the flag (linked document when required).
2. **Tracking Protocols** — interval / recurrence rules.
3. Assign protocols to programs / populations per your site policy.
4. Confirm staff can open **Client Tracking** / related search pages.

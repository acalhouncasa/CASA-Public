---
description: List local SQL tables
---
Use this kit's `.venv\Scripts\python.exe`.

1. Read `memory/INDEX.md` if it exists.
2. List tables and row counts in `data/local.sqlite`.
3. If SQLTools has another connected SQLite or local SQL Server, list those tables too (Windows auth / 127.0.0.1 only).
4. Print column names for each table.
5. Update `memory/data-maps/` for anything new.

Do not connect to a cloud database. Do not install hosted-LLM SDKs.

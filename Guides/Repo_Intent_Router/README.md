# Repo intent router (template)

Large repos work better when people (and AI agents) start from **intent**, not a folder tree dump.

Copy [TEMPLATE_REPO_FIND.md](TEMPLATE_REPO_FIND.md) and fill rows for your shop.

## Tips

- One sentence per link.
- Point to hubs (`RUN_STEPS`, `LESSONS_LEARNED`), not every script.
- Keep private hostnames and credentials out of the public copy.
